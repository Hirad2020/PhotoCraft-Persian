# PhotoCraft فارسی

**فارسی‌ساز: محمد رضا فتحی پور**  
**وب‌سایت: [pcban.ir](https://pcban.ir)**

نسخهٔ فارسی PhotoCraft 0.10.0 برای ویندوز ۶۴ بیتی، همراه با ۴۲۷۱ مدخل ترجمه و چیدمان راست‌به‌چپ پوستهٔ برنامه. مشخصات فارسی‌ساز در **راهنما ← دربارهٔ PhotoCraft** نمایش داده می‌شود.

این پروژه توزیع مستقل فارسی است. پروژهٔ اصلی [storytold/photocraft](https://github.com/storytold/photocraft) است؛ اعتبار نویسندگان و مجوزهای اصلی محفوظ است.

## دریافت و اجرا

بستهٔ ویندوز را از [Releases](https://github.com/Hirad2020/PhotoCraft-Persian/releases) دریافت و در پوشه‌ای جداگانه استخراج کنید. `photocraft.exe` را اجرا کنید و زبان را از مسیر زیر روی **فارسی** بگذارید:

`Edit > Preferences > Interface > Language > فارسی`

پیش از جایگزینی نصب قبلی، اسناد را ذخیره کنید، برنامه را ببندید و از فایل اجرایی اصلی پشتیبان بگیرید. به‌روزرسانی رسمی می‌تواند نسخهٔ فارسی را جایگزین کند.

## سورس و ساخت

فایل `photocraft-persian-source.patch` شامل تمام تغییرات فارسی‌سازی، کاتالوگ و مشخصات فارسی‌ساز است. آن را روی نسخهٔ دقیق زیر از سورس اصلی اعمال کنید:

```sh
git clone https://github.com/storytold/photocraft.git
cd photocraft
git checkout 8d2e615ab93d424c4ec25ab15b4edb5368d1f9a6
git apply ../photocraft-persian-source.patch
cargo build --release -p photocraft --features heif
```

پیش‌نیاز ویندوز: Rust با ابزار MSVC، Microsoft C++ Build Tools و Windows SDK. جزئیات بیشتر در مستندات ساخت پروژهٔ اصلی آمده است. فایل `fa.tsv` کاتالوگ UTF-8 ترجمه است.

## بررسی و محدودیت‌ها

آزمون‌های ترجمه، جای‌نگهدارها و راست‌به‌چپ موفق بوده‌اند. تمام ۱۸۹۰ کلید سنجش‌شدهٔ رابط ترجمه دارند؛ برخی خطاهای داخلی موتور همچنان انگلیسی‌اند. چیدمان داخلی برخی پنل‌ها و مکان‌نمای متن محدودیت‌های پروژهٔ اصلی را حفظ می‌کنند.

مجموعهٔ کامل آزمون‌های رابط نتیجهٔ موفق کامل نداشت؛ یک آزمون mip گرافیکی روی AMD Radeon RX 6800 با Vulkan ناموفق بود. کد پردازش تصویر و GPU در این فارسی‌سازی تغییر نکرده است. این نسخه گواهی امضای دیجیتال ناشر ندارد.

ترجمه با کمک OpenAI Codex و پیش‌نویس ماشینی Google Translate از رشته‌های عمومی پروژه تهیه شده؛ اصطلاحات رایج و جای‌نگهدارها بازبینی شده‌اند. بازبینی انسانی متن‌های کم‌کاربرد همچنان سودمند است.
